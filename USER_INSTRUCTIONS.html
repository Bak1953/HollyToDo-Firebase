Holly's ToDo List

A simple task manager that works on iPhone, iPad, Mac and other devices.

Getting started

  1. Open the app in your web browser using the link you have been given.
  2. The app signs you in automatically as a guest, so you can start using it straight away.
  3. To keep tasks the same across all your devices, make sure you use the same app link on each device.
Tip: Add the app to your Home Screen or Dock so it opens like a normal app.

Installing the app

iPhone or iPad

  1. Open the app in Safari.
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen.
  4. Tap Add.

Mac

Safari (macOS Sonoma or later): open the app, then choose File → Add to Dock.

Chrome or Edge: open the app, look for the install icon in the address bar, or use the browser menu to install the page as an app.

Adding a task

  1. Type the task in the New ToDo box (up to 50 characters).
  2. Choose a Category and a Priority.
  3. Pick an Expected Completion date if you want a reminder.
  4. Add any Resources Needed or Other People's Input.
  5. Tap Add Task.

Managing tasks

  • Mark as Complete: tap the tick (✓) button. Completed tasks move to the Completed Tasks list.
  • Archive: tap the folder (📁) button to move a task to Archived Tasks.
  • Delete: archived tasks can be deleted permanently using the bin (🗑️) button.
  • Sort: use the Sort by drop-down to sort by Category, Due Date or Priority.
  • Print: tap Print Active Tasks to print or save as PDF.

Keeping tasks in sync across devices

Tasks are saved automatically to the cloud. If you open the app on another device using the same link, your tasks will appear after a few seconds.

The app needs an internet connection to sync. Changes made offline will be sent to the cloud once the connection returns.

Reminders

Tap Export to Calendar to download a calendar file of all active tasks that have due dates. Open the file on your device to add the tasks and reminders to Apple Calendar, Google Calendar or Outlook. Each task gets a reminder one day before it is due, and your calendar will sync the reminder to your other devices.

  1. Tap Export to Calendar.
  2. Open the downloaded file when prompted.
  3. Choose the calendar to import into.
  4. Your calendar app will now remind you the day before each task.
Tip: You can export again any time you add new tasks or change due dates.

Troubleshooting

  • Tasks not syncing? Check that you have an internet connection and that you are using the same app link on each device.
  • Calendar reminders not appearing? Make sure you opened the exported file and chose a calendar to import into. The calendar must be enabled in your Calendar app.
  • App looks old after an update? Close the app completely and reopen it. On iPhone/iPad this means swiping it away from the app switcher.
